## Featured resume project

**Actor-Critic — Atlantis Defense:** an agent built with Python and TensorFlow for a custom dynamic defense environment, using a shared state encoder with separate policy and value heads, reward shaping, and adaptive exploration.

Results reported in the resume: 30–50 average survival steps and peak evaluation runs above 70 across 1,000+ training episodes. These are project-specific results, rather than a general benchmark.

This repository contains reports. Consult each report for its implementation and evaluation details; runnable source and a packaged environment are not implied.
